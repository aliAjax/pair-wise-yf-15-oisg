# hxyfront-62003 法医昆虫学样本批次台账

源提示词编号：5

法医昆虫学样本记录工作台（批次台账版），供采样员与鉴定员共用一份本机台账，解决案件穿插送检后进度对不上的问题。

## 功能

- **本机批次**：新建批次仅保存在当前浏览器（localStorage，键 `forensic-entomology-ledger-v1`），不联网、不上传。
- **接收校验**：采样地点、暴露阶段、环境温度、采样时刻缺一项不予接收（逐项标红提示）；案件编号、昆虫种类、发育阶段、保存方式、鉴定备注可后补。
- **批次台账**：列表支持按昆虫种类下拉 + 发育阶段（卵 / 幼虫 / 蛹 / 成虫，兼容"三龄幼虫"等写法）组合筛选；卡片显示案件编号与全部字段，空字段显示"待补录"。
- **送检历史**：同一案件编号可多次送检，历史记录全部保留；最新采样时刻记录的发育阶段自动标记为"当前结论"，其余标为历史送检。
- **重复提示**：案件编号与采样时刻同时重复时拒绝直接写入，提示并定位原记录（原记录保留），可返回修改或显式选择"仍作为重复送检保存"。
- **温度曲线**：SVG 曲线图跟随当前所选批次，按采样时刻排列，显示均值/区间，悬停查看案件、种类与温度。
- **待鉴定统计**：顶部"待鉴定"数量与"发育阶段种类数"随筛选结果实时更新；发育阶段为空的样本计为待鉴定。

## 技术栈

React 19 + Vite 7 + TypeScript（无第三方图表 / UI 库）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62003；生产构建：`npm run build`。

首次打开会写入两个演示批次和若干演示样本；清除浏览器站点数据即可重置。
